# دور UI: ناوبری پایین ۳-تابی + پولیش گاوصندوق و تنظیمات — 1.0.0

**پژوهش:** مطالعات ناوبری موبایل ۲۰۲۶ (designstudio/uxpin/anything): تب‌بار پایین = الگوی طلایی ۳-۵ مقصد؛ لیبل+آیکون اجباری؛ ناحیهٔ شست پایین؛ «منوی سرریز نباید اکشن‌های اصلی را بپوشاند» (الگوی Instagram/X برای اکشن مرکزی برجسته؛ Monzo: شفافیت مالی).

## ۱. منوی ناوبری پایین (DezhBottomNav)
- سه مقصد اصلی: **صندوقچه (راست، آیکون صندوق) — رمزساز (وسط، آیکون کلید در دایرهٔ برجستهٔ 46dp) — تنظیمات (چپ، چرخ‌دنده)**.
- در RTL آیتم اول راست رندر می‌شود → دقیقاً به ترتیب درخواستی؛ آیکون‌ها وکتور رسمی Material هستند (inventory_2/vpn_key/settings) — صفر وابستگی جدید.
- تنظیمات از منوی سه‌نقطه حذف شد و به تب‌بار منتقل شد؛ منو حالا: دسته‌ها، تولید رمز، بررسی بروزرسانی، تم.
- جابه‌جایی تب‌ها: پاک‌سازی backstack و رفتن به ریشه (رفتار استاندارد تب).

## ۲. پولیش گاوصندوق
- **جستجو:** از کادر خطی خشک → فیلد قرصی پر (surfaceContainerHigh) با آیکون ذره‌بین و placeholder (الگوی مدرن).
- **رفع باگ بصری:** ردیف «شمارش/مرتب‌سازی» که بریده می‌شد → شمارش با وزن 1f + بیضی، مرتب‌سازی فقط «آیکون + گزینه» (پیشوند تکراری حذف شد).
- کارت رکورد و FAB سر جایشان؛ تب‌بار جای خالی مردهٔ پایین صفحه را پر می‌کند.
