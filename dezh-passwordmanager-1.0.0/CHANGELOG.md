# تغییرات — دژ پاسارگاد

فرمت: نگارش (تاریخ شمسی) — فهرست تغییرات خلاصه. جزئیات در `docs/` لینک‌شدهٔ هر مورد.

## 1.0.0 (۱۴۰۵)

نسخهٔ اولیهٔ عمومی — یک release با دورهای بهبود مستمر زیر همان شمارهٔ نسخه.

### هستهٔ امنیتی (فازهای ۱–۲)
- گاوصندوق با رمز اصلی: PBKDF2-HMAC-SHA256 (۶۰۰k، هم‌راستا با OWASP) → wrap/unwrap DEK تصادفی با AES-256-GCM؛ فرمت‌های نسخه‌دار `DPKW`/`DPVG`
- کلید session فقط در RAM؛ قفل = صفرکردن کلید (fail-closed)؛ Android Keystore (کلید غیرخروجی) برای متادیتای امنیتی
- throttling نمایی تلاش‌های نادرست (تا ۱۵s) + شمارندهٔ مقاوم به دستکاری
- auto-lock: immediately/1/5/15/30 دقیقه (بدون «هرگز»)؛ قفل روی background/خاموش‌شدن صفحه

### گاوصندوق و داده (فازهای ۳–۵)
- CRUD کامل رکوردها با payload رمز (AES-256-GCM session)؛ دسته‌ها، علاقه‌مندی‌ها، جستجو (رمزگشایی در RAM)، مرتب‌سازی؛ DB بدون هیچ plaintext
- پشتیبان‌گیری/بازیابی رمزگذاری‌شده از طریق SAF: AAD-bound header + checksum + نسخه‌دار؛ wrong-pass جدا از corruption؛ restore با plan شفاف (merge/replace، بدون overwrite خاموش)
- تنظیمات DataStore: تم (روشن/تیره/سیستم)، اکسنت، مقیاس فونت، صفحهٔ شروع، تایم‌اوت کلیپ‌بورد (پاک‌سازی خودکار)، حافظهٔ فیلترها

### ابزار و UX (فازهای ۵–۷)
- مولّد رمز SecureRandom با قیدهای طول/کلاس/حداقل‌ها + متر قدرت entropy-محور (NIST 800-63B، ۳ باند)
- تقویم جلالی (پورت jalaali-js، golden test)؛ تاریخ‌ها شمسی
- آیکون اختصاصی، فونت Vazirmatn (OFL)، برند طلایی، RTL کامل

### دورهای تکمیل 1.0.0 (بعد از release اول)
- **باگ‌فیکس:** نام‌های صادقانهٔ رنگ، حذف auto-lock «هرگز»، متر بازنویسی‌شده، CTA حذف، تاریخ شمسی
- **خودبازرسی ۱+۲:** ۴+۲ باگ شامل پاک‌نشدن کلیپ‌بورد مولّد (تست قطعی گیت‌محور)؛ ۱۸۱ تست
- **بازطراحی UI (M3 Expressive):** حرکت‌های فنری کانونی، StaggerIn، آواتار دسته‌ای، حلقهٔ قدرت، pressScale — همه gated با reduced-motion
- **حفاظت از عکاسی:** تنظیم کاربر برای FLAG_SECURE (پیش‌فرض روشن)
- **ناوبری پایین ۳-تابی:** صندوقچه / رمزساز / تنظیمات + کارت‌بخشی تنظیمات + جستجوی قرصی
- **بررسی بروزرسانی:** چون دستی، تگ GitHub Releases را می‌خواند و صفحهٔ Release را در مرورگر باز می‌کند (مجوز `INTERNET` فقط برای همین)
- **ممیزی کامل دور ۳:** رفع باگ ری‌آرم‌نشدن تایمر کلیپ‌بورد جزئیات (TDD قرمز→سبز) + تأیید خط‌به‌خط کل سورس؛ **۲۰۹ تست، detekt ۰، lint سبز**
- **زنده‌سازی UI:** چیپ‌های پرشدهٔ برند، جستجوی تینت، FAB گرادیانی، حرکت‌های امضا (چرخش دیسک خالی، نفس لوگو)
- **نصب درون‌اپی با PackageInstaller رسمی:** دانلود APK از GitHub Releases درون اپ (allowlist هاست + سقف حجم + digest اختیاری)، اعتبارسنجی package/versionCode/امضا پیش از نصب، گیت یک‌بارهٔ «نصب برنامه‌های ناشناس»، Session رسمی با پنجرهٔ تأیید سیستم، اعلام SUCCESS/ABORTED/BLOCKED/FAILED؛ بدون Play/market و بدون silent install؛ **۲۵۹ تست، detekt ۰، lint سبز**
