# رفع باگ بحرانی + پولیش UI — دژ پاسارگاد 1.0.0

## ۱. باگ بحرانی: «نمیشه رمز ساخت / رکوردهای قبلی خالی و بازنمیشن» — RCA و فیکس
**اثبات با تست (TDD):** تست جدید `CorruptRowContainmentTest` اول FAILED شد با
`CryptoException$CorruptedContainer`، بعد فیکس، بعد سبز.

**RCA:** رمزگشایی هر ردیف (`decryptRow`) بدون محافظ بود؛ یک ردیف ناخوانا (دادهٔ
آسیب‌دیده/ناسازگار) باعث exception داخل flow می‌شد → کل لیست می‌مرد (نمایش خالی/null)
و بازکردن همان رکورد هم exception در scope ویومدل = کرش اپ. چنین خطایی فقط روی
دادهٔ واقعی دستگاه رخ می‌دهد و به همین دلیل تست‌های JVM سبز مانده بودند.

**فیکس (containment انتخابی):**
- ردیف ناخوانا → نادیده گرفته می‌شود؛ بقیهٔ رکوردها سالم نمایش داده می‌شوند (لیست هرگز نمی‌میرد).
- خواندن تکی رکورد ناخوانا → null (صفحهٔ جزئیات پیام «یافت نشد» می‌دهد، نه کرش).
- `VaultSessionLockedException` همچنان propagate می‌شود — سیاست fail-closed حفظ شد (تست قدیمی سبز ماند).
- گارد در init صفحهٔ ویرایش (خطای تنظیمات/خواندن → کرش نمی‌شود).
- **پوشش تستی دو صفحهٔ بی‌دفاع:** `EntryScreensRenderTest` — رندر + اعتبارسنجی + تولید رمز در
  فرم افزودن، و رندر جزئیات رکورد (قبلاً هیچ تستی این دو صفحه را رندر نمی‌کرد).

**تشخیص برای آینده:** اگر اپ دوباره کرش کند، استک‌تریس در
`Android/data/com.pasargad.dezh/files/dezh-crash-log.txt` نوشته می‌شود (new breadcrumb handler) —
آن فایل را برایم بفرستید تا دقیق ریشه‌یابی کنم.
