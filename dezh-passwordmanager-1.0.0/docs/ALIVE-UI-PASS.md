# دور «زنده‌سازی» UI — مطابق اسکیل‌ها + ۱۰٪ قانون اکسنت — 1.0.0

**مراجع به‌کاررفته:** `mobile-app-ui-design` (قانون 60/30/10، یک حرکت امضا در هر صفحه،
سایه‌های نرم هم‌رنگ)، `ux-ui-agent-skills/taste/design-taste` (نوار رنگی تکی = کلیشه؛
اکنت ادویه است، سطح اصلی خنثی)، `taste/motion-choreography` (فقط transform/opacity؛
reduced-motion)، `m3-expressive` (فنرها). الهام «زنده‌بودن» از ClipNote: چیپ‌های پرشدهٔ
رنگی و سطوح تینت‌شده — ترجمه‌شده به برند طلایی دژ.

## تغییرات (خویشتن‌دار و حرفه‌ای — نه شلوغ)
1. **چیپ انتخاب‌شده = پرشدهٔ رنگ برند** (primary/onPrimary) — «همه»، دسته‌ها، «علاقه‌مندی‌ها»
   حالا انتخاب‌شدن را واضح با رنگ اعلام می‌کنند (الگوی ClipNote، با رنگ طلایی خودمان).
2. **جستجوی تینت‌شده**: کادر قرصی با primaryContainer (آلفا 0.55) — زنده ولی آرام.
3. **شستِ رنگی پشت‌زمینه**: گرادیان عمودی خیلی ملایم (background → primaryContainer 14٪)
   پشت کل گاوصندوق — حس عمق بدون «بنر».
4. **FAB گرادیانی**: دایرهٔ primary→tertiary با سایهٔ نرم + pressScale — قلب تپندهٔ صفحه.
5. **حذف نوار رنگی بالای کارت علاقه‌مندی‌ها** (خودِ اسکیل آن را کلیشه می‌داند) → به‌جایش
   **حلقهٔ 2dp برند دور آواتار** رکوردهای علاقه‌مندی.
6. **حرکت امضای صفحهٔ خالی**: دیسک گرادیانی با چرخش آرام ۱۴ ثانیه‌ای (GPU transform؛
   با reduced-motion کاملاً خاموش).
7. **حرکت امضای قفل صفحه**: نفس کشیدن لوگو (اسکیل 1→1.045، ۳.۲ ثانیه، gated).
8. همهٔ حرکت‌های جدید gated با LocalMotionEnabled.
